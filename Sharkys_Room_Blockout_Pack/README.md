# Sharky's Room — Blender Blockout Pack v0.1

这是 Codex / Blender 第一阶段的 source-of-truth。

## 目标
根据 `room_master_reference.jpeg` 制作轻量 Blender greybox/blockout，先验证：
- 房间比例与 Hero Camera 构图
