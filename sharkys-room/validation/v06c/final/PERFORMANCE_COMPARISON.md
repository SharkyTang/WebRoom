# v0.6C 最终性能对照

**最终测量完成21/21检查；“性能无明显回退”验收未通过。** 回收了1,366个严格零面积三角形，保持全部有效表面字节不变；最终C有43,442 triangles / 2,336,368 B / 66 primitives。Hero比B后基线增加40 calls、41,486个可见三角面，三尺寸观察帧间隔增加29.99%–43.07%，桌面/390px活动等权mean增加10.02%/11.18%。2 MB和约55 primitives工作目标也未达到。不能把功能与测量检查通过写成整体性能通过，用户视觉确认另列。

## 已回收项与剩余成本

Hogwarts / Bridge / Plants分别删除602 / 128 / 636个严格零面积面，共1,366面、1,054个未引用顶点；源`.blend`保留原可编辑拓扑，`sourceTriangles`为3,552 / 5,016 / 7,944，最终导出`triangles`为2,950 / 4,888 / 7,308。`scripts/assets/v06c_mesh_cleanup.py`直接复制保留的属性字节，未重算法线；`validation/v06c/final/post-cleanup-visible-geometry.json`证明全部13家有效三角POSITION/NORMAL/UV、winding、材质及节点/TRS精确一致，法线容差为0、当前严格退化面为0。其余10家GLB保持原字节。

初次逐primitive逻辑属性估算41,924 B没有对共享accessor去重；这是候选估算，不是最终节省。当前实际文件比旧账本少31,896 B（包含重新导出时增加的清理说明metadata），以两份实际账本为准。

最终43,442 triangles低于65k工作目标，**2,336,368 B比2 MB多336,368 B，66 primitives比约55多11**。150k triangles / 3 MB库增量 / 同Hero +60 calls的临时审查线均未触及（实际+40 calls），但它们不构成“无明显性能回退”通过；该项仍未通过。保留当前完整收藏轮廓、五盆与四独立灯面，不通过删必要资产或跨锚点/独立表面合并伪造达标。

只读复核未发现未引用mesh/material或重复绘制的完全相同有效三角。两盏台灯几何payload相同，四表面材质数值相同但独立身份是本批要求，不应合并成可变共享材质；跨家底座/车轮等共享buffer需另审资源所有权与回退。另有白城实体内部、局部beam端盖与画层背面等约855 tris的隐藏面候选，其中部分仅为源结构推算；尚未逐面完成安全删除与网页回归，不能写成已优化，也不会直接减少当前primitives/calls。未以任意删除可见细节换取数字。进一步性能取舍需用户审阅当前外观与目标设备实测后决定，本批不自动继续新版本。

## 环境限制与错误口径

SwiftShader是软件渲染，390px为触屏仿真，不是实体GPU/手机；本地已运行的开发服务不是互联网冷启动或生产首屏测试。每状态样本短，未多次重复或计算置信区间；不推算真机FPS。三轮都无pageerror、console error或失败请求；每轮保留7条THREE.Clock弃用/ReadPixels driver stall警告，不称“绝对零警告”。截图有读回成本，Hero先采样后截图，后续活动仍受浏览器调度和诊断开销影响。技术、性能未达项、用户视觉状态须在交付报告中分别记录。
