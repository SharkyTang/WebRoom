# keyboard / v0.6B

原创风格化桌面配件；以冻结占位和当前旧三件/A 暂定风格为准，不声称特定型号复刻，用户视觉待确认。

圆角底壳、分组实体键帽、长空格键、功能/导航/方向键区。键帽有实际间隙和高低层次，无逐键交互和文字贴图；同材质键帽合并。原平面占位和最高点不变，四只脚垫局部 y 到 -.0255 m，实际桌面上留0.5mm接触余量；不移动原锚点。

- 可编辑源 `blender-assets/keyboard_v06b.blend`；导出 `public/models/production/keyboard_v06b.glb`。
- 重建：`node scripts/assets/build-interactive-assets.mjs keyboard`，只覆盖该 B 产物，手改前另存。
- 独立恒等根挂回原 TEC 节点，仍为静态非语义配件；不增加第十个交互 ID、目标、页面或状态。
- 标准PBR，完整 UV/法线，0 嵌图/外部纹理；按同一固定根和材质合并，不跨任何独立轴心。
- 实际 4148 三角面、3 可视网格、3 材质、206,320 B GLB。
- 几何、真实网页可见性、静态点击及周边入口证据见 `validation/v06b/stages/04-*`、`stage-accessories/` 和整批最终报告。

同条件性能首测后收敛本批开销：84 个键帽的细小倒角降为单段，删除位于不透明底壳内的键帽底面；保留可见键区、键缝、不同宽度与颜色分组。键盘从9692降为4148三角面，GLB从269152降为206320B，仍为3个primitive。原始性能/阶段证据保留，最终复测见报告。
