# v0.7A 资料缺口与待确认

所有以下缺口都不阻塞 A 的结构、校验和回归；目前四个真实内容域均未齐备。用户提供材料时仍须指定可展示字段和素材版本。

| ID | 字段/范围 | 用户需提供或确认 | 齐备/后补与处理 |
| --- | --- | --- | --- |
| C01 | profile.about | 对外显示名、headline、介绍段落及允许展示范围 | About最低条件；当前null |
| C02 | profile.education[] | 院校、专业/学位、在读/完成等真实状态；日期只需已知精度 | Education最低条件；当前[]，预计结束须标明 |
| C03 | projects[] | 首批至少1个真实项目的标题、摘要、实际进展、本人职责、技术、背景和贡献 | Projects最低条件；当前[]，不从代码/报告自动代写成果 |
| C04 | coverMediaId / galleryMediaIds | 真实截图、可展示范围、第三方信息处理、素材授权 | 可后补；无图用文字结构 |
| C05 | projects.links | 允许公开的代码/演示/文章链接 | 可后补；没有链接就省略 |
| C06 | portraitMediaId | 可选头像与授权/隐私范围 | 可不提供，不要求露脸 |
| C07 | memories[] / media[] | 相册标题、至少一组允许展示的照片、原件位置由用户指定 | Memories真实内容最低条件；当前[] |
| C08 | images.alt/caption/dateLabel/locationLabel | 每图真实画面说明、允许展示的人物/地点/日期范围、许可来源 | alt与许可必需，其余可省略；不从EXIF或画面推断 |
| C09 | contact.channels[] | 至少一种有效且允许公开的邮箱/主页/渠道；是否首选/可复制 | Contact齐备最低条件；当前[] |
| C10 | 新UI语言/参考 | 中文、英文还是双语；是否有本次批准的设备设计稿 | B01前确认；A沿既有中英混合标题，不生成双语履历 |
| C11 | 垃圾桶 | 保持原彩蛋，或明确给定的新文案及静态范围 | 当前保持原样；不创建删除/清空/随机/持久化系统 |
| C12 | 简历、视频、结果数字、奖项 | 仅用户确有需要时提供真实材料与公开许可；数字附条件/出处 | 不作为本批最低条件；不推定存在 |

历史限制继续登记：C资源/活动软件渲染成本、未测实体手机和平板、Safari/Firefox/硬件GPU/弱网/完整辅助技术、其他模型精修候选。已通过的四组视觉确认无需重新批准。首次 MacBook/钢琴先收再开的节奏未修改，如需改变应另行提出范围。
